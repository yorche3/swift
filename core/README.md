## 🧪 Convenciones / Conventions

**ES:** Los scripts independientes se ejecutan con `swift` o `swiftc`. Los proyectos tipo librería usan Swift Package Manager y XCTest, con código en `Sources/` y pruebas en `Tests/`.

**EN:** Standalone scripts run with `swift` or `swiftc`. Library-style projects use Swift Package Manager and XCTest, with code under `Sources/` and tests under `Tests/`.
