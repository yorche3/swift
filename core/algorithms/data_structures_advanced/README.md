# Data Structures Advanced — Swift

Implementación de la especificación [07_Data_Structures_Advanced](https://yorche3.github.io/programming_languages/core/algorithms/07_Data_Structures_Advanced/) en **Swift**, usando una estructura de librería de **Swift Package Manager** y **XCTest** para las pruebas unitarias.

Este módulo implementa desde cero la clase base `Node` con valor, el nodo `TreeNode` y el árbol binario de búsqueda `BinaryTree`, así como el nodo `GraphNode` y el grafo dirigido `Graph` con registro enlazado canónico y adyacencia ordenada gestionada manualmente.

## 🛠️ Enfoque y construcción / Approach & Build

**ES:** El proyecto se configuró como librería de Swift Package Manager. Se adopta una arquitectura donde los nodos (`Node`, `TreeNode`, `GraphNode`) son tipos de referencia (`class`, `final class`) para permitir mutación directa de enlaces (`left`, `right`, `nextVertex`) en $O(1)$ sin clonar celdas, mientras que los contenedores (`BinaryTree`, `Graph`) son tipos de valor (`public struct`) con métodos `mutating`. `TreeNode` y `GraphNode` reutilizan la base `Node` mediante herencia directa de clases. En `Graph`, el registro de vértices se mantiene en una lista enlazada propia recorrida manualmente en $O(V)$, y la adyacencia se almacena en `[Int]` con inserción ordenada y comprobación de duplicados implementadas manualmente sin delegar en ordenaciones o conjuntos de la biblioteca estándar.

**EN:** The project is configured as a Swift Package Manager library. An architecture is adopted where nodes (`Node`, `TreeNode`, `GraphNode`) are reference types (`class`, `final class`) to allow $O(1)$ direct link mutation (`left`, `right`, `nextVertex`) without cell cloning, while containers (`BinaryTree`, `Graph`) are value types (`public struct`) with `mutating` methods. `TreeNode` and `GraphNode` reuse the base `Node` via direct class inheritance. In `Graph`, the vertex registry is kept as an internal linked list traversed manually in $O(V)$, and adjacency is stored in `[Int]` with manual sorted insertion and duplicate detection without delegating to standard library sorting or set collections.

## 🧠 Algoritmos y operaciones / Algorithms & Operations

| Operación / Operation | Entrada → salida / Input → output | Complejidad / Complexity | Notas / Notes |
|---|---|---|---|
| `Node.init(value)` | `Int → Node` | $O(1)$ | Celda base con valor inmutable / Base cell with immutable value |
| `Node.value` | `() → Int` | $O(1)$ | Lectura de propiedad constante (`let value`) / Constant property read |
| `TreeNode.init(value)` | `Int → TreeNode` | $O(1)$ | Inicializa nodo de árbol con enlaces `left` y `right` en `nil` / Initializes tree node with `left` and `right` links at `nil` |
| `TreeNode.left` | `() → TreeNode?` | $O(1)$ | Lectura y reasignación de enlace izquierdo / Read and reassignment of left link |
| `TreeNode.right` | `() → TreeNode?` | $O(1)$ | Lectura y reasignación de enlace derecho / Read and reassignment of right link |
| `BinaryTree.init()` | `() → BinaryTree` | $O(1)$ | Inicializa raíz en `nil` y contador a 0 / Initializes root to `nil` and count to 0 |
| `BinaryTree.insert(value)` | `Int → Bool` | $O(h)$ | Inserta preservando invariante de ABB ($h$ = altura); duplicado no altera tamaño / Inserts preserving BST invariant ($h$ = height); duplicate does not alter size |
| `BinaryTree.contains(value)` | `Int → Bool` | $O(h)$ | Búsqueda binaria iterativa según invariante de ABB / Iterative binary search following BST invariant |
| `BinaryTree.isEmpty` | `() → Bool` | $O(1)$ | Verifica `_count == 0` / Checks `_count == 0` |
| `BinaryTree.size` | `() → Int` | $O(1)$ | Devuelve el número de nodos almacenados / Returns stored node count |
| `GraphNode.init(label)` | `Int → GraphNode` | $O(1)$ | Inicializa vértice con etiqueta, sin vecinos y sin siguiente en registro / Initializes vertex with label, empty neighbors and no next in registry |
| `GraphNode.hasNeighbor(v)` | `Int → Bool` | $O(d(u))$ | Recorrido lineal manual de adyacencia ($d(u)$ = grado de salida) / Manual linear traversal of adjacency ($d(u)$ = out-degree) |
| `GraphNode.addNeighborIfAbsent(v)` | `Int → Bool` | $O(d(u))$ | Inserción ordenada manual sin duplicados / Manual sorted insertion without duplicates |
| `Graph.init()` | `() → Graph` | $O(1)$ | Inicializa registro de vértices en `nil` y contadores a 0 / Initializes vertex registry to `nil` and counts to 0 |
| `Graph.addVertex(label)` | `Int → Bool` | $O(V)$ | Registra vértice nuevo en cabeza de registro enlazado si no existe / Prepends new vertex to linked registry if absent |
| `Graph.addEdge(u, v)` | `(Int, Int) → Bool` | $O(V + d(u))$ | Añade arista dirigida ordenada si ambos vértices existen / Adds sorted directed edge if both vertices exist |
| `Graph.hasEdge(u, v)` | `(Int, Int) → Bool` | $O(V + d(u))$ | Comprueba existencia de arista entre dos vértices / Checks existence of edge between two vertices |
| `Graph.getNeighbors(u)` | `Int → [Int]?` | $O(V + d(u))$ | Devuelve copia aislada de vecinos o `nil` si no existe / Returns isolated copy of neighbors or `nil` if missing |
| `Graph.isEmpty` | `() → Bool` | $O(1)$ | Verifica `_vertexCount == 0` / Checks `_vertexCount == 0` |
| `Graph.vertexCount` | `() → Int` | $O(1)$ | Devuelve cantidad de vértices registrados / Returns registered vertex count |
| `Graph.edgeCount` | `() → Int` | $O(1)$ | Devuelve cantidad de aristas dirigidas / Returns directed edge count |

## 🧩 Decisiones de diseño / Design decisions

| Decisión / Decision | Alternativa considerada / Alternative | Razón / Reason |
|---|---|---|
| `Node`, `TreeNode` y `GraphNode` como `class` y contenedores como `struct` con métodos `mutating` | Todo como clases por referencia o ADTs basados en `indirect enum` | Permite mutación $O(1)$ directa de enlaces (`left`, `right`, `nextVertex`) sin clonación de nodos, manteniendo semántica de valor limpia e independiente para los contenedores externos. |
| Reutilización de `Node` mediante herencia de clases (`TreeNode: Node`, `GraphNode: Node`) | Composición o valor embebido (`let value: Int` en cada nodo) | Swift soporta herencia directa en clases; permite reutilizar el almacenamiento inmutable de `value` y su constructor base sin duplicar código ni campos. |
| Almacenamiento de vecinos en `[Int]` con búsqueda e inserción ordenada manual | Lista enlazada manual `NeighborNode` o `Set<Int>` de biblioteca | La especificación autoriza colecciones de biblioteca para almacenar vecinos si la búsqueda e inserción ordenada se escriben manualmente; `Array` en Swift posee semántica de valor copy-on-write, garantizando aislamiento estricto al retornar vecinos sin conversiones costosas. |
| `@discardableResult` en `insert`, `addVertex` y `addEdge` | Exigir consumo obligatorio del valor booleano de retorno | Permite invocar las operaciones por su efecto mutador en la estructura sin generar advertencias del compilador cuando no se requiere inspeccionar el resultado. |

## 📝 Notas de implementación / Implementation Notes

- **ES:** La base `Node` almacena únicamente `value` sin validaciones ni enlaces, y sirve de clase base compartida mediante herencia para `TreeNode` y `GraphNode`.
- **EN:** The base `Node` stores only `value` without validations or links, serving as a shared base class via inheritance for `TreeNode` and `GraphNode`.
- **ES:** `TreeNode` añade los enlaces mutables `left` y `right` de tipo `TreeNode?`, inicializados en `nil`. En Swift, `TreeNode` se implementa como clase de referencia (`public final class`).
- **EN:** `TreeNode` adds mutable links `left` and `right` of type `TreeNode?`, initialized to `nil`. In Swift, `TreeNode` is implemented as a reference class (`public final class`).
